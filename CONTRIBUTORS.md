# Contributors

Everyone whose work is in this repository. Generated by `npm run contributors`
from the commits that reached `main`, so nobody has to remember to add a name.
Alphabetical, without commit counts: one line and one hundred lines are both
work this project did not have to do itself.

Korean: [CONTRIBUTORS.ko.md](./CONTRIBUTORS.ko.md)

different account is the likeliest reason, and that is worth fixing rather than
working around.
