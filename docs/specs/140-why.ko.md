# 기능 사양: 취약한 의존성 경로 설명

영문 정본: [140-why.md](./140-why.md)

이 문서는 로컬 npm lockfile의 의존성 경로를 보여 주는 `zero-shelter why <package>` 기능의 번역본입니다. 동작 계약과 범위는 영문 정본을 따릅니다.

- 입력: `why <package>`와 선택적인 `--input`, `--format json`
- 출력: 루트 의존성에서 설치된 취약 패키지 사본까지의 모든 단순 경로, lockfile로 확인할 수 있는 고정 버전 정보
- 제한: 네트워크 조회·설치·파일 쓰기 없음, npm lockfile만 지원
- 오류: lockfile을 읽지 못하거나 패키지가 없으면 종료 코드 2
