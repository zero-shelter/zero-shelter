# QA 체크리스트

기능 명세와 PR에서 이 체크리스트를 사용합니다. 해당하지 않는 항목은 이유를 적고 제거할 수 있습니다.

베타 릴리스 기준, QA 항목 ID, 실행 주기와 날짜별 보고서는 [베타 QA 안내](qa/README.md)를 따릅니다.

## 자동 검증

- [ ] `npm test` 통과
- [ ] `npm run typecheck` 통과
- [ ] `npm run build` 통과
- [ ] 새 동작에 회귀 테스트 추가
- [ ] 필요한 경우 동일 입력의 결과 일치와 입력 순서 영향 검증
- [ ] 지문·해시 변경은 무작정 스냅샷을 재생성하지 않고 의도적으로 확인

## 보안과 개인정보

- [ ] 실행 중 LLM 호출을 추가하지 않음
- [ ] 문서화되지 않은 네트워크 요청·텔레메트리를 추가하지 않음
- [ ] 비밀정보·개인정보를 로그·테스트 입력·수집 자료·보고서에 기록하지 않음
- [ ] 필요한 경우 민감정보 제거·해시 처리를 테스트함
- [ ] 신뢰 경계와 데이터 흐름을 문서화함
- [ ] 실패 동작을 fail-open·fail-closed·warning 중 하나로 명시함
- [ ] 악용·공격 입력을 검토함

## 호환성과 사용자 경험

- [ ] CLI 옵션·종료 코드 호환성 유지 또는 호환성이 깨지는 변경 문서화
- [ ] 텍스트·JSON·SARIF·hook 출력 호환성 유지 또는 문서화
- [ ] README와 관련 문서 갱신
- [ ] 영어 정본 문서 갱신
- [ ] 한국어 번역 갱신 또는 차이 명시
- [ ] 깨끗한 체크아웃 또는 빌드한 패키지에서 예시 명령 실행

## 근거

실행한 명령, 수동 확인 내용, 아직 확인하지 못한 내용을 적습니다.
