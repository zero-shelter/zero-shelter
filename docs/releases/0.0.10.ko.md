# 0.0.10 릴리스 노트

정본: [영어 CHANGELOG의 0.0.10 항목](../../CHANGELOG.md#0010).
이 문서는 해당 버전만 번역합니다.

2026-09-09 정정: 실제 출력 필드는 `security_severity`입니다. 이전 설명의 하이픈 표기를 바로잡았으며 출력 자체는 바뀌지 않았습니다.

## 판정 근거

`history`는 원본 보고 수와 병합 후 건수를 미처리 항목 수 옆에 표시합니다.
`accepted`가 baseline 전체 크기가 아니라 이번 실행에 일치한 baseline 항목
수라는 설명도 추가했습니다. 텍스트와 JSON 모두 저장된 건수를 제공합니다 (#232).

SARIF는 취약점 권고문이 제공한 CVSS 벡터를 `properties.cvssVector`에 그대로
보존합니다. 숫자형 `security_severity`는 기존의 대략적인 심각도 구간을
유지하며, 벡터로 CVSS 점수를 계산하지 않습니다 (#226). HTML의 중복 참조는
같은 화면에 형제 항목이 있으면 취약점 권고문 이름을 표시하고, 없으면 지문을
유지합니다 (#211).

## baseline에 기록한 출처

`--update-baseline`은 확인 메시지 앞에 건너뛴 스캐너 안내를 표시하고,
파일에 기록한 스캐너 출처를 알려줍니다. 지원하는 단일 스캐너 실행은
계속 성공하지만, 스캐너가 빠졌다는 사실을 숨긴 채 기록하지 않습니다 (#227).

## 패키지 매니저별 안내

스캐너가 직접 의존성 여부를 제공하지 않으면 매니페스트에 선언된 패키지를
직접 의존성으로 인식합니다. 옛 npm/pnpm 형식과 OSV에도 적용되며, 수정 버전이
함께 제공된 경우 직접 업그레이드 명령을 표시할 수 있습니다 (#195).
yarn 프로젝트에 npm 잠금 파일을 만들라고 안내하지 않습니다 (#201).
HTML은 npm 이외의 환경에서 검증할 수 없는 `clears N` 배지와 그 건수를
약속하는 문단을 모두 숨깁니다 (#229). 에이전트 스킬은 보고서의 명령과
매니저별 강제 버전 형식을 사용하며, npm 전용 조치가 다시 들어오는 것을
확인하는 QA도 추가했습니다 (#234).

옛 pnpm/npm 6 형식에서는 수정 범위가 `>=1.2.3`처럼 정식 버전의 하한을 포함할 때 그 버전을 전달합니다. 하한을 포함하지 않는 범위, 정식 출시 전 버전, 여러 조건을 조합한 범위에서는 설치할 버전을 추측하지 않습니다 (#233). 한국어 HTML의 점수 근거와 가중치
표를 번역했으며, 영어 터미널과 SARIF의 근거 문구는 유지합니다 (#240).

## 기록과 버전 선택

- 중단된 history 줄에 다음 기록이 이어 붙어 읽히지 않던 문제를 수정했습니다 (#199).
  정정(2026-09-09): 이전 설명은 이후 모든 기록이 유실되는 것으로 영향 범위를 과장했습니다.
- `expiress`처럼 알 수 없는 baseline 항목 키를 경고합니다. 향후 형식과의 호환성을 위해 판정은 계속합니다 (#200).
- 정식 출시 전 버전끼리의 순서를 비교하고, JavaScript의 안전한 정수 범위를 넘는 숫자 식별자도 처리합니다. 버전의 `v` 접두사도 인식합니다 (#170).
- osv-scanner에 검사할 패키지 출처가 없는 경우를 스캐너 실패와 구분합니다 (#190).

## 기여와 설치 검증

기여 가이드와 PR 템플릿에 포크 CI의 Maintainer 승인 대기를 설명했습니다
(#220). CI 예제의 osv-scanner 다운로드는 버전을 고정하고 체크섬을
검증합니다 (#221). 설치 QA의 하위 프로세스와 CI 작업에 시간 제한을 두고,
CLI 제한은 스캐너 제한보다 길게 잡았습니다. 판정하지 못한 이유도 실패한
검사에 표시합니다 (#160). README에 첫 기여 이슈를 찾는 경로를 추가했고
(#164), CODEOWNERS와 브랜치 보호를 통해 Owner 리뷰 요청과 승인·필수
검사를 연결했습니다 (#202). 아키텍처 기여 안내는 두 입력 경로의 매니페스트
문맥 전달을 설명합니다 (#238). 별도 Node 20 CI 작업은 체크섬으로 검증한
런타임에서 명시된 최소 지원 버전을 검사합니다 (#241).

## 호환성과 알려진 한계

기존 judge 종료 코드, 지문 생성 규칙, 순위 가중치, baseline 수용 의미는
바뀌지 않습니다. history JSON 건수와 선택적 SARIF 벡터는 추가 필드이며,
사람이 읽는 출력 문구는 바뀝니다. 항목이 사라져도 반드시 고쳐졌다는 뜻은
아니므로 계속 “더 이상 보고되지 않음”이라고 표현합니다.
패키지·잠금 파일·플러그인 버전은 0.0.10으로 일치합니다 (#203).

옛 형식에서 해석할 수 없는 수정 버전 범위는 설치할 버전을 생략합니다.
한국어 HTML의 중복 항목에
영어 `fixed in` 문구가 남는 문제는 #218에 있습니다. 새 스캐너나 제안된
`scanners` 명령(#163)은 이번 릴리스에 포함되지 않습니다.
